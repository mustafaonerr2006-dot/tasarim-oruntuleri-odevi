# Tasarım Örüntüleri Ödevi

Seçtiğim konu: D - E-Ticaret Sepeti

Bu projede basit bir alışveriş sepeti yaptım. İlk halinde kodu özellikle çok esnek olmayan şekilde bıraktım. Çünkü sonraki fazlarda tasarım örüntüleriyle bu kodu adım adım daha düzenli hale getireceğim.

Başlangıçta sepette ürün ekleme, indirim seçme ve toplam tutarı yazdırma işlemleri var.
